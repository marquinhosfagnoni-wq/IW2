# Calculadora de Velocidade

Projeto desenvolvido na ETEC Antônio Furlan, Barueri/SP.

## Sobre o projeto
Calculadora web que calcula a velocidade média com base
na distância (km) e tempo (horas) informados pelo usuário.
Exibe feedback visual dependendo da velocidade calculada.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Como usar
1. Informe a distância em quilômetros
2. Informe o tempo em horas
3. Clique em "Calcular"
4. Clique em "Limpar" para resetar
